A three-zone economic dispatch you can run in a browser, and four things it refuses to do

Written for an analyst who reads production-cost model output and has no license. This page states what the engine solves, what it leaves out, how close it lands on recorded Philippine prices, and the four ways to run it. It costs nothing and needs no account.

Free, and open all the way down

MIT code, CC-BY-4.0 calculated data, public inputs. The data and the results rebuild from a clean clone.

The browser runs the same solver

HiGHS, compiled to WebAssembly. Python and browser build the same linear program text, byte for byte, and a test pins the hash.

Checked against the market, not against itself

Every recorded day replays against published prices. The error is on the page, not in a footnote.

The engine solves seven things fully, three partly, and skips four

CapabilityHereWhat that means in this engine
Economic dispatch, hourlyYesA linear program over three zones and 24 hours, priced from the balance duals
Transfer limits between zonesYesTwo high-voltage direct-current links, with an hourly limit and a wheeling cost
StorageYesState of charge with a round-trip efficiency, and a free terminal state each day
Reserve, co-optimizedYesReserve-capable capacity cannot sell the same MW twice
Hydro energy budgetYesA daily MWh limit per zone, taken from the recorded day
Value of lost loadYesUnserved load prices at the published market offer cap of P32/kWh
Loss of load probabilityYesRandom forced outages, sampled, reported per zone
Capacity expansionPartlyA least-cost new-build mix over representative periods, on generic cost anchors
Multi-period chronologyPartly168 hours as one program in one view. Everything else solves one day at a time
Unit commitmentNoBuilt and measured. It lowered the price correlation in all five scored series, so it stays off
Named unitsNoThe program holds fuel blocks per zone. You can raise a fuel's MW and cannot add "Unit 3"
Security-constrained nodal dispatchNoA reduced loss surface over mapped routes, checked per zone. It is not a network model
Contracts and settlementPartlyA contract book marks against modeled spot, per contract and net. No capacity fee, no wheeling charge, no tax, no credit terms
Stochastic multi-stageNoRepeated draws over one stage, never a scenario tree

The two No rows at the top are one limit rather than two. The linear program dispatches fuel blocks, so a named unit has nowhere to live and commitment has nothing to commit. The method page carries the measurement that kept it that way.

How close it gets: the offer replay lands between 0.69 and 0.86

Every recorded day replays two ways. The cost model prices a competitive fuel-cost floor. The offer replay clears the market operator's own published bid book. Neither reproduces every price, and the table states the gap that remains. Recorded prices never set the model inputs.

Four ways to run it, and the fastest one takes no install

  • The map. Five modes over the archive, plus a simulate that re-solves in the browser.
  • The studio. Forty-two views, a command palette, and a scenario that travels as a link.
  • Python. pip install power-dispatch-studio, then one line in a notebook. A dated archive snapshot ships inside the wheel, so it runs offline.
  • A clone. make data rebuilds every number from the committed raw files, with no network.

Your own system runs on the same engine

The engine reads a directory holding two files. Write your own pair and it models your system instead of the Philippine one. Nothing in those files has to be Philippine.

pip install power-dispatch-studio
power-dispatch run --data-dir ./mysystem --date 2030-01-01

The data contract lists every key those two files must carry, and carries a 30-line system that runs. A test builds that system, solves it, and fails when the document stops matching the engine.

Four things a licensed tool gives you that this does not

Say it plainly, because you will find it in the first hour anyway.

  • No named unit, so no per-unit commitment, start cost, or minimum run time.
  • No full network model. Transmission geometry comes from OpenStreetMap, and the ratings are class defaults.
  • No multi-year chronology. A year of days is 365 separate 24-hour programs, with storage reset at each midnight.
  • Three zones, so nothing below the island grid except the reduced loss surface.

Everything in that list is a stated limit with a reason, and two of them carry a measurement. The method page holds the rest.
